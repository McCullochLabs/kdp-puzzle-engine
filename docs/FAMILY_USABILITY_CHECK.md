# Short family usability check

This is a test plan, not a claim that the wife or children have tested the app.
Run on the HP at its normal Windows text scaling, with the existing local Ollama model.

Give each person these tasks without describing which buttons to use:

1. Create a birthday activity pack for a named person. Find the actual preview and explain where the answers are.
2. Change the title, close the form, and continue the unfinished work. Recover the previous saved edit.
3. Find an existing book, preview its saved pages/cover, and ask the assistant to change its cover. Verify the correct book stays selected.
4. Ask for another version. Confirm the existing book/package remains unchanged.
5. Stop Ollama temporarily, then attempt an ordinary creation using the guide/buttons.
6. Enter too few words and an invalid page count. Explain the next step from the displayed message.

Record each task as Completed unaided, Completed with help, or Could not complete.
Capture the first confusing label or missing next step, not a guessed persona score.
Check that menus, text entry, Back/Next/Create, preview navigation, and save status remain visible at normal scaling.
Do not approve new artwork or publish a real listing as part of this exercise.
