# Non-Word-Search Catalog Strategy

The existing Catalog Intelligence service owns the read-only expansion plan. “Build Out Other Puzzle Types” displays catalog count, planning range, honest readiness states, strongest opportunity, and next safe action. It does not build or publish.

Planning ranges are 15–25 Mixed, 15–25 Scramble + Trivia, 12–20 Cryptograms, and 12–20 Sudoku. These are direction ranges, never quotas.

Ranking uses local evidence only: strict content state, format capability, catalog gap, audience/archetype fit, marketplace fit, series/bundle potential, cover readiness, overlap risk, and editorial effort. It contains no claimed demand, search volume, sales, competition, or profit prediction.

The fastest safe strategy is to deepen differentiated Sudoku families while creating reviewed, sourced content for themed Cryptogram and Scramble + Trivia products. Mixed products follow only when each component can independently support the promise.
