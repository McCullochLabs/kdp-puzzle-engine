# Content Expansion Campaigns

Use **Expand content** in Book Readiness only when an exact book format is
blocked by reviewed-content capacity. The campaign is specific to that goal,
for example “Unlock Gardening Word Search — 48 × 12.”

Each saved campaign records the current strict capacity, exact shortfall,
recommended review-pool estimate, and eligible existing candidates. Campaigns
are saved in `data/content_expansion_campaigns` and can be resumed safely.

Campaign creation does not generate new content, approve a candidate, rewrite a
source bank, make a book, or publish anything. The next step is to create a
review batch and make explicit human decisions.
