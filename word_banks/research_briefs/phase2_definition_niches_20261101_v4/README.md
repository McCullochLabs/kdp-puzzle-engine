# Additional definition-backed niche review candidates

33 existing untrusted words are organized into 21 niche review groups. This supersedes v1/v2/v3; do not add version counts together. All remain proposed/pending editorial review.11 prior proposals were held for misleading inherited topics, spelling/context or dated-definition concerns. No master vocabulary, saved word store, taxonomy, approvals, or book was changed.

Each canonical record contains its exact WordNet 3.0 definition and synset. WordNet is a historical lexical source, not current science or verified trivia. Source license is included. Prior campaigns are excluded; current campaign versions do not exclude each other. Review holds are retained, not deleted.

Useful groups include geological formations (AQUIFER,PLATEAU), fields of science (ACOUSTICS,THERMODYNAMICS), musical instruments (TAMBOURINE), and workers/trades (PROSPECTOR), subject to the actual candidate file and audience review. Group membership does not establish full-book capacity.
